# Open Ledger · Secret Phrase Wallet Manager

自分だけが覚えているフレーズから、標準的な 24 ワードの BIP-39 ニーモニックを決定論的に生成します。

すべてブラウザ内で動作します。バックエンドなし、ネットワークリクエストなし、テレメトリなし。入力は現在のページのメモリ内にのみ存在します。

> 初期段階のプロジェクト · 独立した監査は未実施 · まずは捨ててもよいテスト用ウォレットで試してください。

## これは何か

フレーズ・シークレット・ワードリスト言語を入力すると、Open Ledger デバイスと同じ Secret Phrase アルゴリズムで 24 ワードの英語 BIP-39 ニーモニックを派生します。さらに任意で BIP-39 passphrase を加えると、ETH / BTC / SOL / TRON / SUI のアドレスと秘密鍵を派生します。

- 同じ入力からは常に同じニーモニックが生成されます
- 出力は標準の BIP-39 ニーモニックで、対応ウォレットにインポートできます
- デバイス実装とバイト単位で一致します（[アルゴリズム](#アルゴリズム)参照）
- フレーズ・シークレット・passphrase・ニーモニック・秘密鍵はページメモリ内にのみ存在し、再読み込みで消えます

## セキュリティモデル

- **100% ローカル**：サーバー、API、アナリティクスはありません。ビルド成果物は静的ファイルです。
- **永続化なし**：入力は `localStorage` / `cookie` / `IndexedDB` に保存されません。
- **秘密鍵を表示します**：エクスポートと照合のため意図的に表示します。自分のオフライン端末でのみ使用し、共用・信頼できないコンピュータでは開かないでください。
- **弱い入力は総当たり可能**：フレーズとシークレットの強度がウォレットの安全性を決めます。強度メーターは目安であり、保証ではありません。
- **入力を忘れるとウォレットを失います**：フレーズ・シークレット・ワードリスト言語・passphrase のすべてが必要です。本ツールは何も復元できません。

## アルゴリズム

1. 選択したワードリスト言語でフレーズを分割します。簡体字・繁体字中国語と日本語は 1 文字ずつ、それ以外は空白で分割して小文字化します。
2. 各トークンを対応する BIP-39 ワードリストで検索します（インデックス 0–2047）。一致しないトークンは無視されます。
3. 一致したインデックスのうち先頭 **48** 個までを使います（フレーズは 1024 文字まで）。
4. 各インデックスを 2 バイトのビッグエンディアンで連結し、`phraseHash = keccak256(indexBytes)` を計算します。
5. シークレットが空でない場合 `entropy = keccak256(phraseHash ‖ keccak256(secret UTF-8))`、空の場合 `entropy = keccak256(phraseHash)` です。
6. 32 バイトのエントロピーを 24 ワードの**英語** BIP-39 ニーモニックに変換します。

分割言語・一致順序・シークレット内容・バイト符号化がすべて結果に影響します。他の「テキストからニーモニック」ツールと互換だとは考えないでください。

権威ある実装とテストベクトルは [open-ledger-app](https://github.com/blockchain-dev-tools/open-ledger-app/blob/main/docs/reference/enigma.md) にあります。

## 互換性に関する注意

一致トークンの上限を 16 から 48 に引き上げました。一致トークンが 16 個を超えるフレーズでは、旧バージョンと現行バージョンで**異なる**ニーモニックが派生されます。旧上限に依存した外部ユーザーはいません。旧バージョンでウォレットを作成した場合は、まずそのバージョンで復元を確認してください。

## 派生パス

| チェーン | パス | 秘密鍵の形式 |
|---|---|---|
| ETH | `m/44'/60'/0'/0/0` | 0x hex |
| BTC | `m/84'/0'/0'/0/0`（P2WPKH） | WIF |
| SOL | `m/44'/501'/0'/0'`（SLIP-10 Ed25519） | base58 · 64B |
| TRON | `m/44'/195'/0'/0/0` | hex |
| SUI | `m/44'/784'/0'/0'/0'`（SLIP-10 Ed25519） | bech32 |
